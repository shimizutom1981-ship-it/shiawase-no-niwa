# しあわせの庭 🌱

余暇の「何をしよう？」を、7種類の幸福経験から探す日本語Webアプリ。

## アプリ
GitHub Pages公開後: https://shimizutom1981-ship-it.github.io/shiawase-no-niwa/

## 機能（MVP v0.1）
- 7種類（つながる・楽しむ・上達する・発見する・創り出す・役に立つ・整える）と「おまかせ」
- 利用できる時間による絞り込み
- 体験履歴を考慮したアイデアの抽選
- 3段階評価、履歴表示・削除
- 端末内localStorage保存（アカウント・外部API不要）

## 実行
`index.html` をブラウザで開く。GitHub Pagesでも動作します。

## 注意
幸福の7分類と提案ロジックは実用的な試案であり、幸福の向上を科学的に保証するものではありません。履歴はブラウザごとに保存され、別端末には同期されません。
